# ComfyUI 工作流图形参数编辑器 PRD

## 1. 文档信息

- **产品名称**：ComfyUI 工作流图形参数编辑器
- **目标载体**：配置页本地 ComfyUI 工作流编辑器、画布生成配置节点
- **文档状态**：已实现，待人工验证
- **目标用户**：使用本地 ComfyUI 自定义 API 工作流，并希望在画布中可视化调整参数的用户
- **关联文档**：[画布连线绑定 ComfyUI 工作流参数](/zh-CN/docs/progress/canvas-comfyui-parameter-binding-prd)、[本地 ComfyUI 配置模块 PRD](/zh-CN/docs/progress/comfyui-local-config-prd)

## 2. 背景与问题

当前自定义 ComfyUI 工作流已经可以以 API JSON 导入，并定义 `prompt`、`negativePrompt`、`width` 等参数。参数编辑仍然偏向表格或配置字段，用户需要记住节点 ID、输入名和参数机器名，难以判断工作流的真实数据流，也不容易发现参数映射错误。

参考仓库 [hero8152/Infinite-Canvas](https://github.com/hero8152/Infinite-Canvas) 的 `static/js/api-settings.js` 使用以下模式：

1. 读取 API 工作流 JSON 的节点和输入连接。
2. `computeRhWorkflowEditorLayers` 按依赖关系计算节点层级。
3. `renderRhWorkflowEditorGraph` 使用 SVG 绘制节点、连线、类别颜色和已暴露数量。
4. 点击 SVG 节点后，`openRhWorkflowNodePopover` 打开节点参数 Popover。
5. 参数字段支持勾选暴露、改显示名、改类型、配置默认值、范围、枚举和必填状态。
6. 左侧字段列表与图中节点高亮同步，图区域支持滚轮缩放、拖拽平移和适应窗口。

本项目应吸收该交互模型，但将“参数机器名”与当前项目已有的 `CanvasConnection.parameterKey`、`CanvasNodeMetadata.comfyUiParameterBindings` 对齐，避免再引入一套只在配置页有效的绑定协议。

## 3. 产品目标

- 用节点图让用户能快速理解 ComfyUI 工作流的节点依赖和输出路径。
- 点击任意节点即可查看其可写输入，并在同一处将输入暴露为工作流参数。
- 将工作流参数定义与画布连线绑定解耦：工作流负责 `parameterKey -> nodeId/inputKey`，画布只引用 `parameterKey`。
- 暴露参数后，在左侧摘要、节点图徽标和画布生成配置中保持一致。
- 在保存、切换工作流、导入导出和重试时保持参数契约稳定，并为失效绑定提供可定位提示。

## 4. 非目标

- 第一版不提供完整 ComfyUI 节点编辑器，不修改节点类型、连接关系或任意 JSON 字段。
- 第一版不自动猜测节点标题、输入名和画布文本之间的语义关系；用户必须显式暴露和绑定。
- 第一版不在图编辑器内实现图片、视频、音频上传到 `LoadImage` 等素材节点；媒体参数沿用现有执行器限制。
- 不改变非 ComfyUI 模型和未设置 `parameterKey` 的旧画布行为。

## 5. 核心概念与职责边界

### 5.1 工作流节点图

工作流图只展示 API JSON 中的节点和节点间输入连接。节点位置由依赖层级计算得到，用户可以平移和缩放视图，但第一版不保存手工布局，也不允许在图上改变工作流连接。

### 5.2 工作流参数

工作流参数是稳定的公开契约：

```ts
type ComfyUiWorkflowParameter = {
  key: string;                 // prompt、negativePrompt、width
  label: string;               // 正面提示词、宽度
  valueType: "string" | "number" | "boolean" | "enum" | "image" | "video" | "audio";
  defaultValue?: string | number | boolean;
  required?: boolean;
  options?: string[];
  min?: number;
  max?: number;
  step?: number;
  bindings: Array<{ nodeId: string; inputKey: string }>;
};
```

工作流参数编辑器允许编辑契约字段，但不直接把整份工作流 JSON 写进画布节点。

### 5.3 画布参数绑定

画布连接保存 `parameterKey`，例如“正面提示词文本 → 生成配置”的连接绑定 `prompt`。生成时由画布收集来源值，执行器依据工作流参数的 `bindings` 写入 ComfyUI 节点输入。两层关系如下：

```text
画布连接.parameterKey = "negativePrompt"
              ↓
工作流参数 negativePrompt.bindings = [{ nodeId: "4", inputKey: "text" }]
              ↓
workflow["4"].inputs.text = 来源文本
```

## 6. 用户流程

### 6.1 导入并查看

1. 用户在“本地 ComfyUI”服务中导入 API 格式 JSON。
2. 系统解析节点、输入连接、可写字段和图片/视频/音频输出节点。
3. 打开“图形编辑”后，中央区域显示按依赖层级排列的节点图，左侧显示节点总数、参数数和输出节点。
4. 节点颜色只表达输入类别，不把颜色当作参数状态；已暴露节点使用更粗描边，当前节点使用高亮描边。

### 6.2 点击节点并暴露参数

1. 用户点击图中节点，右侧检查器（窄屏时为底部抽屉）切换到该节点。
2. 检查器按输入字段列出 `inputKey`、识别类型、当前值和来源状态。
3. 用户点击“添加为工作流参数”，系统生成或建议参数机器名，并立即在左侧参数列表和节点徽标中显示。
4. 对已暴露字段，用户可以修改显示名、类型、默认值、必填、枚举选项和数值范围。
5. 保存前实时提示重复 key、空 key、绑定到不可写输入和类型不一致等问题。

### 6.3 与画布配合

1. 用户保存工作流后，在画布生成配置节点选择该工作流。
2. 用户选中“文本节点 → 生成配置节点”的连接，在现有连接浮层中选择工作流参数。
3. 连接标签显示短参数名；图形编辑器中对应参数和节点显示已使用状态。
4. 工作流参数被重命名、删除或目标输入变化时，画布连接显示失效状态，生成前阻止提交并提供重新绑定入口。

## 7. 功能需求

### FR-01 图形化布局

- 从 API JSON 的 `[nodeId, outputIndex]` 输入引用建立有向图。
- 使用拓扑深度作为横向层级；同层节点按 nodeId 稳定排序，循环或孤立节点放入起始层并显示提示。
- 节点最小信息：显示标题、`class_type`、nodeId、可暴露字段数。
- 连线使用曲线连接节点右侧到下游节点左侧；重复边合并，避免同一对节点多条线覆盖。
- 图区域提供缩小、放大、当前比例和适应窗口；滚轮以指针位置为中心缩放，按住空白区域拖拽平移。
- 节点点击与画布平移不冲突：拖拽位移超过阈值后不打开参数检查器。

### FR-02 节点检查器

- 检查器标题显示节点标题、nodeId 和 `class_type`。
- 每个输入字段显示：输入名、数据类型、默认值/当前值、是否已暴露。
- 可写输入支持一键“添加为工作流参数”；不可识别或由上游连接产生的输入显示只读原因。
- 已暴露输入显示参数 key、显示名、类型、默认值、必填和范围等编辑控件。
- 关闭检查器、切换节点或刷新页面前，未保存修改要显示“有未保存修改”状态，不丢失内存草稿。

### FR-03 参数定义

- 参数 key 必须以字母或下划线开头，只允许字母、数字、下划线和短横线，长度 1-64。
- 同一工作流内 key 唯一；建议 key 默认取 `inputKey`，冲突时追加 nodeId 后缀并允许用户修改。
- 类型至少支持：多行文本、单行文本、数字、滑块、开关、枚举、图片、视频、音频。
- `number/slider` 支持 `min`、`max`、`step`；`enum` 支持每行一个选项；媒体类型显示素材适配状态。
- `required` 只决定画布生成前是否必须有最终值，不改变 ComfyUI 原始输入的连接语义。
- 一个参数可以绑定同一节点的一个输入或多个兼容输入；多个绑定写入前必须通过类型兼容校验。

### FR-04 参数与画布绑定

- 复用当前 `CanvasConnection.parameterKey?: string`，不保存 nodeId 或 inputKey。
- 连接参数下拉显示 `label (key) · 类型`，搜索同时匹配 label 与 key。
- 当前工作流不存在的 key 显示 `Invalid`，不能静默回退为普通提示词。
- 未绑定连接继续走既有文本合并、参考素材和组节点逻辑。
- 一个字符串参数可接受多个文本连接，沿连接顺序用空行合并；数字、布尔和枚举参数出现多个来源时阻止生成。

### FR-05 校验与错误反馈

- 保存工作流时校验：key 格式和唯一性、节点存在性、输入存在性、类型与默认值、范围关系、枚举非空。
- 生成前校验：工作流引用有效、连接 key 有效、标量来源无冲突、值可转换、必填项有值。
- 图中错误节点使用红色状态点或边框，左侧参数列表显示错误数量；点击错误项定位节点和字段。
- 工作流重新拉取后保留同名 key 的字段配置；无法匹配的字段进入“待处理变更”列表，不覆盖用户草稿。

### FR-06 持久化与历史

- 工作流配置保存到当前本地 ComfyUI 服务的工作流记录中，包含工作流 JSON、参数契约、输出节点和版本号。
- 画布项目只保存工作流引用、`parameterKey` 和生成节点已有的参数值，不嵌入整份工作流 JSON。
- 生成记录保存服务 ID、工作流 ID/版本、最终参数快照和连线绑定快照，重试时以快照为准。
- 导入导出画布和配置时保留参数 key；未知字段按不兼容状态显示，不覆盖原始配置。

### FR-07 状态与响应式

- 空状态：没有工作流节点时显示导入入口和 API JSON 格式说明。
- 加载状态：解析和重新拉取期间保留标题，图区域显示进度，不允许保存半成品。
- 错误状态：JSON 非 API 格式、节点引用损坏、输出节点缺失、ComfyUI 不可达均有可读错误。
- 窄窗口下布局降级为“图在上、参数列表和检查器在下”；检查器最大高度受视口约束，字段区域可滚动。
- 浅色/深色主题沿用 `canvasThemes` 的背景、边框、文字和节点颜色，不在业务组件内硬编码一套主题分支。

## 8. 数据结构建议

```ts
type ComfyUiWorkflowConfig = {
  id: string;
  serviceId: string;
  title: string;
  description?: string;
  version: number;
  workflowJson: Record<string, { class_type: string; inputs: Record<string, unknown>; _meta?: { title?: string } }>;
  parameters: ComfyUiWorkflowParameter[];
  outputNodes: Array<{ nodeId: string; inputKey?: string; type: "image" | "video" | "audio" }>;
  updatedAt: number;
};
```

参数配置和工作流版本必须同一条记录保存；画布和历史记录只引用 `id + version`，避免工作流重导入后改变历史任务含义。

## 9. 分阶段实施计划

### Phase 1：只读图形编辑器

- 抽取 ComfyUI API JSON 的节点、边、输入和输出解析工具。
- 新增图形编辑器页面/弹窗，完成 SVG 分层、连线、缩放、平移、节点选择。
- 接入当前 `canvasThemes`，补齐空、加载、错误状态。

### Phase 2：参数检查器与契约保存

- 实现节点输入列表、暴露切换、参数 key/label/type/default 编辑。
- 加入范围、枚举、必填和重复 key 校验。
- 保存工作流参数契约和输出节点配置，支持重新拉取后的变更提示。

### Phase 3：画布联动与生成校验

- 复用 `CanvasConnection.parameterKey` 的绑定入口，增加参数失效定位。
- 将参数收集、类型转换、冲突和必填校验接入生成/重试。
- 保存生成参数快照，补齐导入导出和历史恢复。

### Phase 4：体验优化

- 参数搜索、批量暴露、键盘导航、图中错误定位。
- 保存手工布局（可选），增加工作流版本 diff 和批量重绑定。
- 评估图片、视频、音频参数的上传适配。

## 10. 验收标准

- 导入包含文本编码、采样器、尺寸和输出节点的 API JSON 后，节点按依赖从左到右排列，所有连接可见且无重复边。
- 点击任意节点后检查器只显示该节点输入；点击“添加为工作流参数”后，左侧参数数、节点徽标和字段状态立即同步。
- 可以分别把两个文本编码节点的 `text` 暴露为 `prompt` 与 `negativePrompt`，并在画布连接浮层中选择这两个 key。
- `width`、`height`、`steps` 等数字字段支持默认值、范围和步长；非法值在保存或生成前阻断并定位到字段。
- 工作流切换或重新拉取导致 key 失效时，连接和参数列表显示失效状态，修复前不提交 `/prompt`。
- 刷新、关闭重开、导入导出和重试后，工作流参数契约、画布 key 和历史快照保持一致。
- 普通模型、未绑定连线和旧项目的生成结果不受影响。
- 浅色和深色主题下节点图、检查器、弹层文字均有足够对比度；窄窗口不出现横向溢出。

## 11. 风险与限制

- ComfyUI 自定义节点的输入 schema 不统一，自动识别类型只能作为建议，必须允许用户手动修正。
- 工作流内部连接可能占用某个输入；编辑器应提示“由上游节点提供”，不能让用户误以为参数写入一定生效。
- 节点图很大时，SVG 全量渲染和边计算可能影响性能；超过约 200 个节点后需要评估虚拟化或分块渲染。
- 浏览器直连本地 ComfyUI 仍受 CORS、鉴权和服务状态影响，错误反馈必须保留原始 HTTP 状态和可读建议。
