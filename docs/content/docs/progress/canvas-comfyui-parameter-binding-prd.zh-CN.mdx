# 画布连线绑定 ComfyUI 工作流参数 PRD

## 1. 文档信息

- **产品名称**：画布 ComfyUI 工作流参数绑定
- **目标载体**：无限画布、画布生成配置节点、本地 ComfyUI 自定义工作流
- **文档状态**：已实现，待人工验证
- **目标用户**：需要在画布中分别组织正面提示词、负面提示词和工作流自定义参数的本地 ComfyUI 用户
- **关联文档**：[本地 ComfyUI 配置模块 PRD](/zh-CN/docs/progress/comfyui-local-config-prd)

## 2. 背景与问题

当前画布连接到生成配置节点后，普通文本输入会被合并为一份提示词。自定义 ComfyUI 工作流虽然已经可以定义 `prompt`、`negativePrompt`、`width` 等参数，并将参数绑定到具体的 ComfyUI 节点输入，但画布中的来源节点还不能选择自己对应的工作流参数。

因此，用户无法稳定表达以下关系：

```text
正面提示词文本 ──▶ prompt
负面提示词文本 ──▶ negativePrompt
采样步数文本   ──▶ steps
```

如果仅根据画布节点标题、文本内容或工作流节点名称猜测绑定关系，会产生重名、跨工作流复用和误匹配问题。本需求增加显式的“参数名绑定”，由用户选择画布连线对应的工作流参数。

## 3. 产品目标

- 让画布来源节点可以显式绑定到当前 ComfyUI 工作流的参数机器名。
- 支持两个或多个文本节点分别绑定 `prompt`、`negativePrompt` 等参数。
- 复用工作流已有的参数定义和类型校验，不让画布直接依赖 ComfyUI 节点 ID。
- 同一画布节点连接不同工作流时，可以使用不同的参数绑定。
- 保留未设置参数名时的现有画布生成行为。
- 保存绑定关系，确保刷新、重试和历史记录恢复后语义不丢失。

## 4. 非目标

- 不让画布节点直接填写或依赖 ComfyUI 节点 ID；节点 ID 只属于工作流参数定义内部。
- 第一版不通过参数名自动上传图片、视频或音频到 ComfyUI 的 `LoadImage` 等输入节点。
- 第一版不猜测节点标题、文本标题或 ComfyUI 节点名称的语义。
- 不改变普通 OpenAI、Gemini 或其他非 ComfyUI 模型的输入逻辑。
- 不修改本地 ComfyUI 工作流编辑器中已有的参数定义、节点绑定和输出节点配置。

## 5. 核心概念

### 5.1 工作流参数机器名

工作流参数的 `key` 是稳定的机器名，例如 `prompt`、`negativePrompt`、`steps`。它由工作流编辑器定义，并绑定到一个或多个 `nodeId + inputKey`。

画布只引用这个 `key`，不保存 ComfyUI 节点编号。这样工作流内部调整节点编号时，画布仍然只依赖工作流公开的参数契约。

### 5.2 连线参数绑定

参数绑定属于“来源节点 → 生成配置节点”的连线，而不是来源节点本身：

```text
CanvasConnection {
  fromNodeId: "正面提示词",
  toNodeId: "生成配置",
  parameterKey: "prompt"
}
```

同一个文本节点可以连接到多个生成配置节点，并在每条连线上使用不同的 `parameterKey`。同一个生成配置节点也可以接收来自不同节点的 `prompt` 和 `negativePrompt`。

### 5.3 未绑定连线

`parameterKey` 为空表示用户没有选择显式工作流参数。未绑定连线继续走现有逻辑：普通文本作为生成提示词合并，图片、视频和音频按当前画布生成输入规则处理。

## 6. 用户流程

### 6.1 配置工作流参数

1. 用户在配置页导入或编辑 ComfyUI API 格式工作流。
2. 在“输入参数”中定义参数机器名、显示名称、类型、默认值和 ComfyUI 节点输入绑定。
3. 保存工作流并确保每个需要被画布使用的参数都已通过校验。

### 6.2 在画布上绑定参数

1. 用户创建文本、图片或其他内容节点，并将其连接到生成配置节点。
2. 生成配置节点选择一个 ComfyUI 自定义工作流。
3. 用户选中一条连接，在连接设置中打开“参数名”。
4. 系统读取当前工作流的 `parameters`，以下拉选项显示参数显示名和机器名。
5. 用户选择 `prompt`、`negativePrompt` 或其他参数并保存。
6. 画布连接线上显示已绑定参数的简短标识；未绑定时不显示额外标签。

### 6.3 生成与重试

1. 用户点击生成。
2. 系统按显式连线参数收集来源节点值，并与生成配置中的参数值合并。
3. 系统按工作流参数定义进行类型转换和校验。
4. 校验通过后，将最终参数写入对应 ComfyUI 节点输入并提交 `/prompt`。
5. 生成记录和结果节点保存工作流引用、参数快照及连线绑定快照。
6. 用户重试时优先使用生成记录中的快照，不因当前工作流或当前画布连接后来改变而改变原任务语义。

## 7. 功能需求

### FR-01 连线数据

- `CanvasConnection` 增加可选字段 `parameterKey?: string`。
- `parameterKey` 只保存工作流参数机器名，不保存显示名称、节点 ID 或完整工作流 JSON。
- 空字符串按未绑定处理，持久化时可以省略该字段。
- 同一来源节点连接不同目标生成配置节点时，每条连线独立保存参数名。
- 删除连线时同步删除该连线的参数绑定；删除节点时沿用现有连线清理逻辑。

建议类型：

```ts
export type CanvasConnection = {
  id: string;
  fromNodeId: string;
  toNodeId: string;
  parameterKey?: string;
};
```

### FR-02 参数选择入口

- 只有目标节点是生成配置节点，且其当前模型是 ComfyUI 自定义工作流时，才显示“参数名”设置入口。
- 参数选项来自当前服务和工作流的 `parameters`，不从节点标题或节点输入名称临时扫描。
- 每个选项至少显示参数 `label`、`key` 和类型。
- 提供“未绑定”选项，用于恢复当前默认输入行为。
- 工作流切换后，原连线参数名若在新工作流中不存在，标记为失效并要求重新选择。
- 普通模型、内置调用脚本和没有参数定义的工作流不显示该入口，避免让用户误以为绑定会生效。

### FR-03 来源值读取

- 文本节点读取 `metadata.content`，必要时回退到现有文本读取逻辑。
- 生成配置节点自身的提示词编辑内容继续按现有逻辑处理，不自动伪装成某条来源连线。
- 第一版显式参数绑定支持文本节点作为标量参数来源。
- 图片、视频、音频和扩展节点的参数名可以显示为不可用状态，并提示需要单独的素材上传适配；不能静默把媒体 Data URL 写入数字或字符串参数。
- 来源节点为空时，按工作流参数的必填和默认值规则校验，不发送空的隐式值覆盖默认值。

### FR-04 参数合并与优先级

- 显式连线绑定的值优先于生成配置节点中同名的手动参数值。
- 没有显式连线值时，使用生成配置节点保存的参数值。
- 两者都没有值时，使用工作流参数的 `defaultValue`。
- 必填参数经过以上步骤仍无值时，生成前显示“请填写参数”错误，不提交 ComfyUI 任务。
- 同一个字符串或多行文本参数允许多个文本节点绑定，按照 `connections` 数组顺序以 `\n\n` 合并。
- 同一个数字、布尔或枚举参数只允许一个有效来源；出现多个来源时阻止生成并提示冲突的节点和参数名。
- `prompt` 和 `negativePrompt` 都按字符串参数处理，允许分别接收多个文本来源，但不能把负面提示词混入正面提示词。
- 已显式绑定到 `prompt` 的文本不应再次作为未绑定文本追加，避免重复提示词。

### FR-05 类型校验

- 参数绑定必须引用当前工作流中存在的 `parameter.key`。
- 来源值按工作流参数的 `valueType` 转换，复用现有 ComfyUI 执行器的字符串、数字、布尔和枚举转换规则。
- 数字参数无法转换、超出最小值或最大值时，生成前显示参数名和来源节点。
- 枚举参数的值不在工作流选项中时，阻止生成。
- 工作流编辑后导致参数类型或绑定目标变化时，重新校验所有相关连线。
- 参数失效、类型冲突和重复标量来源都必须在画布上有可定位的错误提示。

### FR-06 执行器集成

- 生成配置节点执行 ComfyUI 工作流前，先建立“参数机器名 → 最终值”的映射。
- 执行器继续只根据工作流参数的 `bindings` 写入 ComfyUI 节点输入，画布层不得直接修改节点 JSON。
- `/prompt`、`/history/{prompt_id}`、`/view`、取消和错误处理沿用现有 ComfyUI 执行器。
- 画布连线参数映射不改变现有 ComfyUI 服务、工作流选择和输出节点逻辑。
- 同一个生成配置节点的每次提交都使用当次计算出的参数快照，不能在轮询过程中读取已变更的画布连线。

### FR-07 持久化与历史

- 画布项目保存 `parameterKey`，刷新后恢复连接上的参数选择。
- 生成配置节点保存当前工作流引用和手动参数值，继续沿用现有 `comfyUiParams`。
- 生成记录保存：服务 ID、工作流 ID、工作流名称、最终参数值和参与映射的连线快照。
- 工作流被删除或重命名后，历史记录仍显示生成时的工作流名称和参数快照。
- 导出和导入画布项目时保留连线参数名；不支持该字段的旧数据按未绑定连线读取。

### FR-08 与现有行为兼容

- 未绑定参数名的旧连线继续使用当前文本合并、参考素材和组节点输入逻辑。
- 仅当用户明确设置 `parameterKey` 时，才启用显式参数映射。
- 切换回普通模型时，保留 `parameterKey` 数据但不执行映射；切回同一工作流后恢复使用。
- 复制节点或复制连接时，沿用现有复制规则复制参数名；如果目标工作流不一致，复制后的失效状态必须可见。

## 8. UI 需求

### 8.1 连接设置

建议在选中连接后的轻量浮层中展示：

```text
连接参数
来源：负面提示词
目标：本地 Z-Image

参数名  [negativePrompt ▼]
类型    多行文本
状态    已绑定
```

- 采用现有画布浮层、主题和 Ant Design `Select` 样式。
- 参数名显示为“显示名称（机器名）”，搜索同时匹配两者。
- 连接目标不是 ComfyUI 自定义工作流时显示“当前模型不支持参数绑定”，不显示可编辑下拉框。
- 错误状态显示失效参数名和“重新选择”操作。
- 绑定成功后，连线标签只显示短机器名，例如 `prompt`、`negativePrompt`；过长参数名使用省略并保留悬浮完整提示。

### 8.2 生成前检查

点击生成时按以下顺序检查：

1. 目标工作流是否仍存在。
2. 所有显式参数名是否存在于当前工作流。
3. 是否存在重复标量来源。
4. 来源值是否能通过参数类型和范围校验。
5. 必填参数是否有最终值。

检查失败时，生成配置节点保持可编辑状态，并提供定位到相关连接的入口；不创建空结果节点，不提交 `/prompt`。

## 9. 数据流

```text
画布连接
  └─ parameterKey
       ↓
读取目标生成配置节点的 ComfyUI 工作流
       ↓
按连接收集来源值
       ↓
与 comfyUiParams 合并并按 key 校验
       ↓
workflow.parameters[key].bindings
       ↓
写入 ComfyUI node.inputs[inputKey]
       ↓
/prompt → /history → /view
```

画布层只负责来源值和参数名，工作流层负责参数类型与 ComfyUI 节点输入绑定，执行器负责提交任务和读取结果。三层职责不能通过标题猜测或共享整份工作流 JSON 混合。

## 10. 验收标准

- 一个文本节点绑定 `prompt`，另一个文本节点绑定 `negativePrompt`，生成请求中两个 ComfyUI `CLIPTextEncode` 输入分别收到对应内容。
- 两个文本节点都绑定 `prompt` 时，最终正面提示词按连接顺序合并一次，内容不重复。
- 两个文本节点绑定同一个 `steps` 或 `seed` 时，生成前明确提示冲突，不提交任务。
- 文本节点绑定数字参数 `steps`、`cfg` 或 `width` 时，合法文本可转换为数字，非法文本显示参数错误。
- 工作流切换后，原工作流存在而新工作流不存在的参数显示失效状态，修复前不能生成。
- 删除或断开显式参数连线后，该来源不再写入对应参数；其他未绑定输入仍按旧逻辑工作。
- 未设置任何 `parameterKey` 的旧画布项目，生成结果与本需求上线前一致。
- 刷新画布、关闭后重新打开项目、重试历史任务后，参数名和最终参数快照保持一致。
- 同一文本节点连接两个不同生成配置节点时，可以分别选择不同参数名，互不覆盖。
- 普通模型和自定义调用脚本不显示 ComfyUI 参数绑定入口，也不改变现有请求结果。
- 图片、视频或音频绑定到不兼容标量参数时显示明确限制，不把媒体内容直接写入工作流。

## 11. MVP 范围与后续迭代

### 首期必须交付

- `CanvasConnection.parameterKey` 数据字段。
- 连接参数选择入口和当前工作流参数列表。
- 文本节点到字符串、数字、布尔、枚举参数的映射和校验。
- 多文本字符串参数的确定性合并。
- 重复标量来源、失效参数和类型错误的生成前阻断。
- 生成、重试、历史和画布持久化中的参数快照。
- 旧连线未绑定时的现有行为兼容。

### 后续迭代

- 图片、视频、音频节点到 ComfyUI 素材输入的上传和文件名映射。
- 参数绑定的拖拽端口、批量绑定和参数模板。
- 显式调整同一字符串参数多个来源的排序，而不依赖 `connections` 数组顺序。
- 工作流参数变更后的批量重绑定工具。
- 连接标签、参数状态和批量生成检查的更细粒度可视化。

## 12. 风险与限制

- 工作流参数 key 被用户重命名后，已有画布连线可能失效，需要提供清晰的失效提示。
- 同一个自定义节点输入可能被工作流内部连线占用，最终是否可写仍以工作流参数校验结果为准。
- 依赖浏览器直连本地 ComfyUI 时，CORS、服务状态和第三方节点错误仍可能导致任务失败。
- 字符串转数字或布尔值虽然方便，但可能掩盖用户输入错误，因此必须在提交前展示转换失败信息。
- 参数绑定属于画布项目数据，不能只存在于当前 React 状态或临时生成请求中。

## 13. 实现顺序建议

1. 扩展 `CanvasConnection` 类型和画布项目持久化。
2. 增加连接参数编辑入口，读取当前生成配置节点的 ComfyUI 工作流参数。
3. 抽取“连接参数收集与合并”纯函数，覆盖多文本和标量冲突规则。
4. 在画布生成入口接入合并结果，并复用现有 ComfyUI 参数转换和执行器。
5. 保存生成快照、补充错误定位和历史重试恢复。
6. 完成正面/负面提示词、数字参数、工作流切换和旧项目兼容的人工验收。
